## How to add art

1. Pick an asset below. Copy its prompt into ChatGPT and attach your reference images (the
   brothers, plus the current version of the asset from `assets/reference/`, enlarged 6x, when there is one).
2. Save what ChatGPT gives you into **`assets/raw/`**, named as the asset says ("Drop as").
3. Run **`npm run assets`**. Then `npm run dev` and look at it in the game.

### Naming

- `mendy_small.png` — the whole asset: every frame, in the grid the prompt asked for.
- `mendy_small-run.png` — just one pose's frames (here `run-1`, `run-2`, `run-3`), left to right.
- `mendy_small-crouch.png` — just one frame. Overrides that frame in a whole-asset image, so you can redo one bad frame.
- PNG, JPG or WebP. Transparent backgrounds are kept; a flat `#FF00FF` magenta background is removed;
  for sprites, any other flat background colour touching the edges is removed too.

### Sizes

Sizes are given at **1920x1080**. The game itself is built on a 320x180 screen — exactly one sixth — and
scaled up to fit, so every 1080p size is 6x the game size. The pipeline keeps the 1080p master in
`assets/processed/hd/` and snaps a game-size copy to the game's pixel grid; that copy is what the game draws.
A frame's size is fixed by its hitbox in the game, so ChatGPT's image does not have to match it: the
pipeline trims and scales.

### In the game

The new art is a **preview** until it is switched on for everyone (`NEW_ART_BY_DEFAULT` in
`src/config/processedArt.ts`): the plain address still shows the original art. To see the new art, add to the
address: `?art=mix` (new art where it exists, original for the rest) or `?art=new` (only the new art, with
coloured boxes for what is still to be drawn).
