# Credits

Every third-party asset used in this project is tracked here, with its source
and licence, as required by the design doc (§2, §13). Anything requiring
attribution also goes on the in-game credits screen.

## Assets

No third-party asset has been added to this repository. Every image file in the
project is original work. Anything not yet drawn is a plain rectangle generated
at runtime in `src/util/textures.ts`.

| Asset | Used for | Source | Licence |
|---|---|---|---|
| `public/sprites/*.png` (25 sheets) | Both brothers in all five forms, the pigeons, the rats, the Pigeon King, the cart, the scaffolding pipe, the stroller, coins, boxes, crates, flames, the hat | Original work for this project, generated by `tools/art/generate.py` | Owned by the project |
| `public/tiles/*.png` (9 tiles) | The Boro Park tileset — brick, sidewalk, asphalt, scaffolding, fire escape, awning, sewer grate, window | Original work for this project, generated by `tools/art/generate.py` | Owned by the project |
| `public/sprites/backdrops/*.png` (12) | Three parallax layers — sky, skyline, shopfronts — in day, dusk and night, plus the taller skies for the climb in 1-2 | Original work for this project, generated by `tools/art/scenery.py` | Owned by the project |
| `public/sprites/ui/*.png` (5) | World map nodes and path, the kiddush table, the four prize icons, the HUD icons | Original work for this project, generated by `tools/art/scenery.py` | Owned by the project |
| `public/sprites/{goal_meat_board,checkpoint,van,reinforced_block,weak_floor}.png` | Level furniture | Original work for this project, generated by `tools/art/scenery.py` | Owned by the project |

Sprites are authored as text grids inside `tools/art/generate.py`, and the
scenery is drawn procedurally in `tools/art/scenery.py`. No binary asset is
hand-edited, so a recolour or a restyle is a diff rather than a redraw. Run
`npm run art` to regenerate the sprites and `npm run art:scenery` for the
backdrops and interface. Nothing is traced, copied or derived from another game,
and no reference material from another game is stored in this repository (§2).

`npm run check:art` fails the build if a sheet on disk stops matching the frame
sizes `src/config/sprites.ts` slices it by.

## A note on the movement figures

Mendy's speeds, accelerations and jump gravities are taken from published
figures for Super Mario Bros. (NES), at the developer's request, and are marked
`[SMB]` in `src/config/Tuning.ts`.

This is a deliberate decision and the design doc allows for it: §2 says "game
mechanics and genre conventions are not protected and are fine to imitate
freely". What is being used is a set of numbers describing how fast a character
moves — not code, not art, not audio, not names. No Nintendo file of any kind
has been downloaded, referenced, or committed to this repository, and nothing
in the game is named after anything of theirs.

## Rules for adding to this file

- Commercial use must be permitted: CC0, CC-BY, or an explicit permissive licence.
- Record the source URL and the licence at the moment the file is added, not later.
- **No Nintendo asset, sprite, sound, name, or character, ever** — not as a
  placeholder, not as reference, not temporarily.
