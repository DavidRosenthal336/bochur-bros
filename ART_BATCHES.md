# Bochur Bros — art in batches

> **Generated by `npm run assets`** from `tools/assets/batches.mjs`. Every run rewrites it with what is done.

Each batch is **one ChatGPT request** that makes many pieces of art in one picture. For each one:

1. Attach 3 pictures: **Mendy** (`assets/raw/mendy_small.png`), **Berel** (`assets/raw/berel_small.png`) and the
   batch's **reference** (the current art, laid out the way the new picture should be).
2. Paste the prompt.
3. Save what comes back as `assets/raw/batches/<batch id>.png` and run `npm run assets`. It is cut into its pieces
   on its own. If one row comes out badly, redo just that piece and save it in `assets/raw/` under its own name.
